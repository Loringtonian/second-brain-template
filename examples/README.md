# Examples — Synthetic Template Demonstrations

> **These files are 100% fictional.** They demonstrate the three template types
> (A/B/C) on a made-up persona — **Robin Vale**, a coastal-ecology product
> designer who keeps a second brain. None of this is real content. Replace the
> `examples/` folder (or ignore it) once you've built your own.
>
> The persona is deliberately coherent so the examples cross-reference each
> other (a fictional project "TidePool," a flagship writing project "The Salt
> Archive") — that's how a real second brain links ideas across templates.

| File | Template | What it shows |
|------|----------|---------------|
| `template_a_example.md` | **A** — Original Thinking | The owner's own idea, captured verbatim, with the full Metadata→Original Text skeleton |
| `template_b_example.md` | **B** — External Reference | Someone else's content (a podcast snip) with full attribution + the owner's relevance notes |
| `template_c_example.md` | **C** — AI Synthesis | AI-written publishable prose synthesized FROM the owner's notes, text-first, `Review status: Unread` |
