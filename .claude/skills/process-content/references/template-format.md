# Template Format

## Template A Structure (Original Thinking)

```markdown
# [Descriptive Title]

## Metadata
**Source type:** [Dictation/Voice Note/Brain Dump/etc.]
**Source ID:** [timestamp or identifier]
**Created date:** [today's date]
**Primary:** [category from CONTENT_TAXONOMY.md]
**Projects:** [matching projects or None]
**Artifact status:** Nugget

## Summary
[1-3 sentences - PRESERVE USER'S EXACT LANGUAGE]

## Classification
**Primary:** [from taxonomy]
**Secondary:** [if applicable]

## Project Connections
[from INTELLECTUAL_LANDSCAPE.md or "None - General Reference"]

## Keywords
[unique words, people, organizations, project names]

## Source
**Type:** [Dictation/Voice Note/etc.]
**File:** [source description]
**Date:** [date]

## Status
Nugget

## Inspiration Source (if applicable)
[what triggered the thought]

---

## Original Text
> [exact preserved text]
```

## Output Format

```markdown
# Processed Content

**Source:** [description]
**Ideas Found:** [count]
**Date Processed:** [today]

---

## Idea 1: [Title]

[Full Template A]

---

## Idea 2: [Title]

[Full Template A]
```

## Key Principles

1. **PRESERVE EXACT LANGUAGE** - User's keywords are sacred
2. **SEPARATE DISTINCT IDEAS** - One idea per object
3. **WATCH FOR NESTED IDEAS** - Extract all concepts
4. **DON'T SAVE YET** - Verify first, then save
